Report an Error

Found something wrong, or have a suggestion? Email hello@halfave.co with any errors or suggestions, and send a screenshot of what you saw.

What to Include

  • A screenshot of the page showing the error
  • The page link, or the plan ID (for example CD260081, shown on each result)
  • What looks wrong, and what you expected to see

The Condo Book Project shows public filings as the Attorney General posted them, so we can fix how we read or display a document, but the filing itself can only be changed through the Attorney General.
