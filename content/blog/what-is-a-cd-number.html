The Short Answer

A CD number is the plan ID the New York State Attorney General gives a condominium offering plan. It is two letters and six digits, for example CD250420. It's the most reliable way to identify a condo's filing: names change, addresses have several spellings, but the plan ID stays with the filing and every amendment to it.

How to Read a CD Number

Take CD250420, the Morgan Condominium at 38 East 35th Street in Manhattan:

PartValueWhat it tells you
CDPrefixA condominium plan
25Two-digit yearThe year the plan came in: 2025
0420SequenceA four-digit serial number

The Morgan's ID carries 2025, and the plan was accepted for filing on July 1, 2026. That gap is normal: the Attorney General reviews a plan before accepting it. Across the 8,000-plus accepted plans on Open Book, the year in the plan ID is never later than the year of acceptance, and a little under half were accepted in that same year; the rest were accepted a year or more later.

Older plans work the same way: an ID starting CD06 is from 2006, and one starting CD98 from 1998.

CD vs. CC and Other Prefixes

Of the {{stat:plans_total}} plan records on Open Book, {{stat:plans_cd}} start with CD and {{stat:plans_cc}} start with CC. The Attorney General lists most CC plans as combined cooperative/condominium offerings. The prefix is a filing category, so always check the plan type on the record rather than assuming from the letters.

Where to Find a Building's CD Number

  • In the Attorney General's database. Search the building's address or name in the Real Estate Finance database; the plan ID is at the top of the record. Step-by-step instructions: how to search the AG's offering plans.
  • On Open Book. Search the address and the plan ID is on the result. Every building page shows it, and the buildings directory links every condo offering plan by borough.
  • From the new filings list. Recently accepted plans are on the 10 newest NYC condo filings, CD numbers first.

What You Can Do With a CD Number

  • Pull up the filing directly. Type it into the AG's database or Open Book's search and you land on one building, with no guessing about spellings.
  • Find every amendment. Amendments are filed under the same plan ID. See how to find and read offering plan amendments.
  • Tell look-alike buildings apart. Two condos at nearby addresses, or a building that was re-filed after a failed first plan, will have different plan IDs.
  • Cite it. In emails to a lawyer, lender or broker, the plan ID removes any doubt about which filing you mean.

Common Questions

Is a CD number the same as a BIN or BBL?

No. A BIN (building identification number) and BBL (borough, block and lot) are New York City identifiers for a building and a tax lot. A CD number identifies an offering plan filed with the New York State Attorney General. One building can have more than one plan over the years.

Does a CD number change when the plan is amended?

No. Amendments are numbered (Amendment 1, 2, 3…) under the same plan ID.

Can I search Open Book by CD number?

Yes. Paste the plan ID into the search box, for example CD250420.
