# Extractor: howto → template `steps`

"How do I file / register / apply…".

## Search
- The agency's own instructions page and the form/portal it points to. One recent practitioner walkthrough to catch steps the agency page leaves out.

## Fields
`steps`: [{ do, where, fee?, time? }] in order; `fee` as a cited figure. `needs`: documents/IDs to have ready. `deadline`: when it's due and the penalty if a source gives one. `sources`.

## Reconcile
Agency page beats walkthrough; if the walkthrough adds a step, keep it and cite it.

## Fallback
No agency page → `steps` from two agreeing walkthroughs with a caveat. Nothing → `direct`.
